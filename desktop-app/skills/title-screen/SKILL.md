# AI 技能 · 列表标题预筛

本技能只服务一个场景：列表页只有标题 / 公司 / 薪资 / 地点 / 标签，没有 JD 正文，用最少判断排除
「一眼就不该投」的岗位。**拿不准一律保留。**

## 判定依据

以调用方给出的【候选人背景】为准（画像摘要、主投方向、明确不考虑的方向）。
没有背景时只做最保守的判断，不得凭常识想象。

## 排除（命中任一）

1. **方向明显不符**：行业 / 职能 / 技术域与主投方向明显无关，且看不到可迁移路径。
2. **层级明显偏低**：实习、兼职、助理、专员、初级（候选人本身是应届 / 初级时除外）。
3. **明确不考虑**：命中候选人背景里的「明确不考虑」。
4. **性质明显不符**：销售、客服、售前、实施、驻场、外包、纯支持 / 值守，且与主投方向无关。
5. **硬条件可直接判定**：背景里的地点、薪资、公司类型等，在列表信息里就能看出明确不符。

## 保留（不要排除）

- 与主投方向同域或相邻的岗位；
- 层级略低但方向一致的岗位；
- 信息不足、看不准的岗位。

## 尺度

- 只做「一眼」判断；需要读 JD 才能判断的，留到详情阶段，不在本阶段下结论。
- 宁可多开一次详情，不可误杀。
- 不确定是否属于候选人的方向时保留。

> 本技能是通用默认口径。用户可在设置 →「AI 技能」里编辑本文件，或新建同作用域技能
> （例如按自己的行业 / 职级标准），代码不需要改动。
